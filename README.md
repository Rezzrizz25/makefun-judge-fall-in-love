> I still check the passenger seat for you at red lights, three years after you stopped riding shotgun, and my hand still reaches.

## About

One line, written to make the reader fall in love. It holds a single small, true detail — glancing at the empty passenger seat at a red light — and lets the body finish the sentence: three years on, the hand still reaches. No slogan, no praise, just longing that never learned to stop.

## How to run

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or to the script's own directory when that variable is not set). Node standard library only, no network, no dependencies, fully deterministic.
